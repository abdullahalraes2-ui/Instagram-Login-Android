# Instagram Login Android UI

A complete Instagram login interface for Android using Java and Material Design components.

## Project link

https://github.com/abdullahalraes2-ui/Instagram-Login-Android

## Features

- Instagram-inspired login screen
- Empty email/username and password fields
- Material style input boxes
- Login button with validation
- Forgot password link
- Facebook button style
- Sign up section
- Java implementation

## How to run

1. Open the project in Android Studio.
2. Let Gradle sync finish.
3. Run the app on an emulator or Android device.

## Notes

This is a static UI screen matching the Instagram login look and feel, with the input fields kept empty as requested.
